# Hi, I'm Aquaticat

Front-end developer and UI/UX designer.
I turn designs into production HTML, CSS and TypeScript,
and I build the tooling that lets AI coding agents work safely on a large codebase.

## What I work on

- **[Monochromatic](https://github.com/Aquaticats/Monochromatic)**:
  a TypeScript and Rust monorepo of developer tooling, coding-agent plugins, custom linters and Wayland desktop apps.
  Most of the code is written by AI coding agents;
  I design the architecture and the guardrails they work within, and review what ships.
- **[forbidden-strings](https://github.com/Aquaticats/Monochromatic/tree/main/package/forbidden-strings)**:
  a Rust secret scanner built on its own linear-time regex engine.
  Rules support intersection and complement,
  findings never print the matched text,
  and it starts within a sub-100 ms pre-commit budget.
- **Upstream**:
  engine fixes, fuzzing and CI in [resharp](https://github.com/ieviev/resharp),
  and a documentation fix plus bug reports with minimal reproductions in [pnpm](https://github.com/pnpm/pnpm).
